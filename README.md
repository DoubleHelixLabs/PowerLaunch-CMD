# PowerLaunch-CLI
Welcome to the PowerLaunch User Manual!
PowerLaunch is an open source Python CLI that is made for new users.
Inside this repository there will be:

PowerLaunch Packages - Packages to extend the functionality of PowerLaunch.
Command Documentation - Commands to get you started in the CLI.
The source code - The source code of PowerLaunch CMD. (May be used under the GNU public license 2.0)

Star this repository to be the first to know when Powerlaunch releases!
