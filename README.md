# PowerLaunch-CMD
# USER MANUAL:
Welcome to the PowerLaunch CMD User Manual!
PowerLaunch CMD is an open source Python CLI that for all users.
Inside this repository is:

PowerLaunch Packages - Packages to extend the functionality of PowerLaunch CMD.
Command Documentation - Commands to get you started in the CLI.
The source code - The source code of PowerLaunch CMD. (May be used under the GNU public license 2.0)

# COMMAND DOCUMENTATION

help - The standard command to get started in most terminals.
exit - Exit PowerLauch CMD.
clear - Clear the terminal screen.
system <command> - runs a command with your built in terminal, to run commands outside of PowerLaunch CMD.
